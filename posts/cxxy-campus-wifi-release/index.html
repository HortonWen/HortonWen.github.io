发布校园网一键连接 / 自动登录工具（Windows）

发布于：2026-09-20  •  阅读时间：1 min

Windows 电脑连上 Student_CX 后经常不弹认证页，每次都要手动找页面、输账号。这个小工具把「连 WiFi → 等网关 → 自动登录 → 失败兜底弹页面」串成一次点击。

要点：

  • 自动连接无线信号，等待认证网关可达
  • 解析认证页真实字段自动提交，失败再尝试 Dr.COM ePortal 接口
  • 两步都失败时自动弹出认证页，不影响手动登录
  • 密码默认不保存；勾选后才用 Windows DPAPI 账户级加密存到本机，不写明文

工具已开源（cxxy-campus-wifi），使用说明见小工具页面。自动登录接口按学校公开资料编写，尚未在校园实网完整验证，状态记在问题记录里。
