C 语言字符串知识点系统总结

Published: 2026-08-01  •  Reading Time: 3 mins

C 语言中没有真正的”字符串类型”，字符串本质上是以 '\0'（空字符，ASCII 值为 0）结尾的字符数组。这个看似简单的设计背后藏着大量容易踩坑的细节：字符数组和字符指针的区别、sizeof 和 strlen 的混淆、缓冲区溢出、忘记终止符……这篇文章把 C 语言字符串的全部知识点做一次系统梳理，帮你建立起完整的认知框架。

字符串的本质

char str[] = "hello";

内存布局：

'h' 'e' 'l' 'l' 'o' '\0'

关键点：'\0' 是字符串结束标志，没有 '\0' 的字符数组不等于字符串。

字符串的定义方式

字符数组形式（可修改）

char str1[] = "hello";      // 自动分配 6 字节（含 \0）
char str2[6] = "hello";
char str3[10] = "hello";    // 剩余部分补 '\0'

内容可修改：

str1[0] = 'H';   // OK

字符指针形式（指向字符串常量）

char *str = "hello";

"hello" 是字符串常量，内容不可修改（未定义行为）：

str[0] = 'H';   // ❌ 错误

但指针本身可以改指向：

str = "world"; // OK

手动初始化

char str[] = {'h', 'i', '\0'};

忘记 '\0' 会导致字符串操作出错，不推荐这种写法。

字符串的输入输出

printf / puts

printf("%s\n", str);
puts(str);     // 自动换行

scanf（不安全）

char str[20];
scanf("%s", str);

问题：不能读取空格，容易缓冲区溢出。更安全的写法：

scanf("%19s", str); // 限制长度

gets（已废弃 ❌）

gets(str); // 永远不要用

fgets（推荐 ✅）

fgets(str, sizeof(str), stdin);

特点：安全、会读入换行符 \n、自动加 \0。去除换行符的常用写法：

str[strcspn(str, "\n")] = '\0';

常用字符串函数（string.h）

函数功能
strlen求字符串长度（不含 \0）
strcpy字符串拷贝
strncpy安全拷贝（但不自动补 \0）
strcat字符串拼接
strncat安全拼接
strcmp比较字符串
strncmp比较前 n 个字符
strchr查找字符
strstr查找子串

示例：

strlen("abc");        // 3
strcmp("abc", "abd"); // <0
strcpy(s1, s2);
strcat(s1, s2);

常见坑：

char s[5];
strcpy(s, "hello world"); // ❌ 溢出

字符串与指针的关系

char *p = "hello";
char s[] = "hello";
对比项char *pchar s[]
存储位置常量区栈区
是否可修改❌✅
sizeof指针大小数组大小
作为参数退化为指针退化为指针
sizeof(p); // 4 或 8
sizeof(s); // 6

字符串作为函数参数

数组名会退化为指针，以下两种写法等价：

void print(char *s) {
    printf("%s\n", s);
}

void print2(char s[]) {
    printf("%s\n", s);
}

字符串常量的存储

char *a = "hello";
char *b = "hello";

编译器可能让 a == b，因为它们指向同一块只读内存。

动态字符串（堆区）

char *s = malloc(20);
strcpy(s, "hello");
free(s);

注意事项：记得 free、防止越界、防止悬空指针。

常见错误总结

忘记 '\0'：

char s[5] = {'h', 'e', 'l', 'l', 'o'}; // ❌ 缺少终止符

使用未初始化的字符数组：

char s[10];
printf("%s", s); // ❌ 内容不确定

修改字符串常量：

char *p = "abc";
p[0] = 'x'; // ❌ 未定义行为

混淆 sizeof 和 strlen：

char s[] = "abc";
sizeof(s); // 4（含 \0）
strlen(s); // 3（不含 \0）

易混概念速记表

表达式含义
'a'字符，int 类型
"a"字符串（含 \0）
char s[]可修改字符串
char *s指向字符串常量
\0字符串结束符
strlen实际字符数
sizeof占用内存大小

小结

  • C 语言字符串是以 '\0' 结尾的字符数组，没有独立的字符串类型。
  • char s[] 存储在栈区、内容可修改；char *s 指向常量区、内容不可修改。
  • 输入字符串推荐使用 fgets，避免使用已废弃的 gets 和不安全的 scanf("%s")。
  • strlen 计算实际字符数（不含 \0），sizeof 计算内存占用（含 \0），两者不要混淆。
  • 使用 strcpy、strcat 等函数时务必确保目标缓冲区足够大，否则会导致溢出。
