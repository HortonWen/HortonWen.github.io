MATLAB 基础语法与矩阵计算

发布于：2026-08-11  •  阅读时间：6 mins

MATLAB 的全称是 Matrix Laboratory（矩阵实验室），矩阵操作是它最核心的能力。要熟练使用 MATLAB，一方面需要掌握变量、控制流、函数等基础语法结构，另一方面要理解各种矩阵创建、运算和分析方法。这篇文章将这两部分内容整合在一起，从基础语法讲起，逐步过渡到矩阵计算的实战操作，最后给出代码效率优化的实用建议。

基础概念与环境

基本工作流程

MATLAB 提供三种主要的工作方式：命令行交互（直接在命令窗口输入表达式，结果自动显示，除非用分号 ; 抑制输出）、脚本文件（将多行命令保存为 .m 文件，便于重复执行和调试）以及函数文件（封装可重用代码，支持输入输出参数）。

工作区管理

x = 5.71; A = [1 2 3; 4 5 6; 7 8 9];  % 创建变量，无需声明类型

who   % 列出所有变量
whos  % 显示变量详细信息（大小、类型等）

save('data.mat');  % 保存所有变量
load('data.mat');  % 加载变量

核心语法结构

了解了工作环境之后，下面逐一介绍 MATLAB 的核心语法要素。

变量与数据类型

命名规则是以字母开头，可包含字母、数字和下划线，区分大小写（如 myVar_1）。常用数据类型包括：

  • 标量：a = 5
  • 向量：v = [1 2 3]（行向量）或 v = [1; 2; 3]（列向量）
  • 矩阵：M = [1 2; 3 4]
  • 字符串：s = "Hello" 或 s = 'Hello'
  • 逻辑值：true 或 false

此外还有几个常用的特殊变量：ans（最近一次无赋值语句的结果）、pi（圆周率 π）、Inf（无穷大）、NaN（非数值）。

运算符与表达式

  • 算术运算符：+ - * / ^（幂运算）
  • 关系运算符：== ~= < > <= >=
  • 逻辑运算符：&（AND）、|（OR）、~（NOT）、&&（短路 AND）、||（短路 OR）
  • 特殊字符：% 单行注释，%{ %} 多行注释，; 结束语句并抑制输出，... 续行，: 冒号表达式（如 1:10）

控制流语句

if 语句

if x > 0
    disp('正数');
elseif x < 0
    disp('负数');
else
    disp('零');
end

循环语句

for 循环：

for i = 1:5
    disp(i);
end

while 循环：

i = 1;
while i <= 5
    disp(i);
    i = i + 1;
end

break 和 continue

break 终止当前循环，continue 跳过本次循环的剩余部分。

函数与脚本编写

掌握了基础语法之后，就可以把常用的代码封装成函数来提高复用性了。

函数定义

function result = add_numbers(x, y)
    % 计算两个数的和
    result = x + y;
end

函数名与文件名必须一致，支持多输入/输出参数：[sum, product] = calc(x, y)。

匿名函数

对于简短的一次性计算，可以用匿名函数简化写法：

f = @(x) x^2 + 2*x + 1;  % 定义匿名函数
result = f(3);             % 调用函数

数据可视化基础

MATLAB 的绘图功能是其一大亮点，下面分别展示二维和三维绘图的基本用法。

二维绘图

x = 0:0.1:10;
y = sin(x);
plot(x, y);     % 绘制曲线
xlabel('x轴');
ylabel('y轴');
title('正弦函数');
grid on;        % 显示网格

三维绘图

[x, y] = meshgrid(-2:0.1:2, -2:0.1:2);
z = x.^2 + y.^2;
surf(x, y, z);  % 绘制曲面

矩阵创建

从这一节开始进入 MATLAB 最核心的矩阵计算部分。先来看如何创建各种类型的矩阵：

% 直接创建矩阵
A = [1, 2, 3; 4, 5, 6; 7, 8, 9]

% 特殊矩阵
zeros(3, 3)      % 3×3零矩阵
ones(2, 4)       % 2×4全1矩阵
eye(3)           % 3×3单位矩阵
rand(3, 3)       % 3×3随机矩阵
diag([1, 2, 3])  % 对角矩阵

% 等间距向量
linspace(0, 10, 5)  % 0到10之间5个等间距点

前面在基础语法中提到的 zeros、ones、eye、rand、linspace 在这里有了更完整的使用场景。

基本矩阵运算

有了矩阵之后，就可以进行各种运算了。注意区分矩阵运算和元素级运算：

A = [1, 2; 3, 4];
B = [5, 6; 7, 8];

% 加减法
C = A + B
D = A - B

% 矩阵乘法
E = A * B

% 元素级运算（点运算）
F = A .* B    % 元素相乘
G = A ./ B    % 元素相除
H = A .^ 2    % 元素平方

% 转置
A_transpose = A'

下面这张表格总结了容易混淆的运算符区别：

操作说明
*矩阵乘法
.*元素级乘法
/右除
\左除（解线性方程）
'共轭转置
.'普通转置

矩阵分析

除了基本运算，MATLAB 还提供了丰富的矩阵分析函数：

A = [1, 2, 3; 4, 5, 6; 7, 8, 9];

% 行列式
det(A)

% 逆矩阵
inv(A)

% 秩
rank(A)

% 特征值和特征向量
[V, D] = eig(A)

% 奇异值分解
[U, S, V] = svd(A)

% 迹
trace(A)

矩阵索引与操作

灵活地访问和修改矩阵元素是日常使用中最频繁的操作之一：

A = [1, 2, 3; 4, 5, 6; 7, 8, 9];

% 访问元素
A(2, 3)        % 第2行第3列
A(:, 2)        % 第2列
A(2, :)        % 第2行
A(1:2, 1:2)    % 子矩阵

% 修改元素
A(1, 1) = 10

% 矩阵拼接
C = [A, B]     % 水平拼接
D = [A; B]     % 垂直拼接

% 矩阵大小
size(A)
length(A)

线性方程组求解

矩阵计算的一个经典应用就是求解线性方程组 Ax=bAx = bAx=b：

% Ax = b 的解
A = [1, 2; 3, 4];
b = [5; 6];
x = A \ b      % 左除（推荐）
x = inv(A) * b % 等价但效率较低

推荐使用左除 \ 而非 inv(A) * b，因为左除在数值稳定性和计算效率上都更优。

实用示例

最后补充几个常用的矩阵计算操作：

% 计算矩阵的幂
A = [1, 2; 3, 4];
A_squared = A^2

% 矩阵指数
expm(A)

% 条件数（判断矩阵是否病态）
cond(A)

% 范数
norm(A, 2)     % 2-范数
norm(A, 'fro') % Frobenius范数

实用技巧与最佳实践

代码效率优化

  • 向量化操作：优先使用向量运算代替循环

    % 低效：使用循环
for i = 1:1000
    y(i) = i^2;
end

% 高效：向量化操作
y = (1:1000).^2;

  • 预分配数组：避免在循环中动态扩展数组，这是 MATLAB 性能优化中最基本也最有效的手段。

调试技巧

  • 设置断点：在代码行号左侧点击。
  • 使用 disp() 或 fprintf() 输出中间结果。
  • 利用 MATLAB 调试工具：单步执行、查看变量值。

常用快捷键

  • F5：运行脚本
  • Ctrl+C：中断执行
  • Up/Down：浏览历史命令
  • Tab：自动补全命令

小结

  • MATLAB 基础语法涵盖变量定义、运算符、控制流和函数编写，分号可抑制输出，% 用于注释。
  • 矩阵创建支持直接赋值和 zeros、ones、eye、rand、diag、linspace 等特殊矩阵函数。
  • 矩阵乘法用 *，元素级运算用 .*、./、.^，两者不可混淆；左除 \ 是求解线性方程组的推荐方式。
  • 矩阵分析函数包括 det、inv、rank、eig、svd、trace、cond、norm 等。
  • 向量化操作和预分配数组是 MATLAB 性能优化的两大核心手段，应优先于循环写法。
