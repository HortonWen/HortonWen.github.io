🧰 校园网一键连接 / 自动登录

Windows 电脑连上 Student_CX 后经常不弹认证页，每次都要手动找页面、输账号。这个工具把「连 WiFi → 等网关 → 自动登录 → 失败兜底弹页面」串成一次点击。

查看 GitHub 仓库

要解决的问题

  • Windows 连接 Student_CX 后，浏览器不自动弹出上网认证页面
  • 认证页地址和触发方式记不住，每次都要翻说明
  • 同一时间段最多 3 台设备在线，频繁切换设备时容易“登录超限”
  • 想开机自动联网，但每次都要手动操作一遍

工作流程

  1. 自动连接无线信号：本机没有配置时，自动创建一份开放网络的无线配置再连接
  2. 等待认证网关可达：探测网关的 8080 / 80 端口，确认链路就绪
  3. 先检查是否已经在线：访问公开检测页，已认证就直接结束
  4. 获取认证页面：访问触发地址，跟随跳转拿到真实认证页和表单
  5. 自动提交登录表单：按页面真实字段填入账号、密码和出口线路，带隐藏字段一起提交
  6. 失败则尝试 Dr.COM ePortal 接口：用本机 IP / MAC 拼常见接口再试一次
  7. 兜底：两步都失败时，自动弹出认证页，手动输一次也能用

界面与功能

  • 连接并自动登录：主按钮，执行上面的完整流程
  • 只打开认证页面：不输账号，只把认证页弹出来
  • 检查网络状态：看当前连的无线和是否已通过认证
  • 自助服务：打开自助平台，处理账号绑定、注销在线设备
  • 清除保存：删掉本机加密保存的登录信息

图形界面可填：信号名、账号、密码、出口线路（校园内网 / 中国电信 / 中国移动），以及是否本机加密保存密码。

密码安全

默认不保存密码，每次打开手动输入。只有勾选「本机加密保存」后，才会用 Windows 账户级加密（DPAPI）存到 %APPDATA%\CXXY-CampusNet\cred.bin，仅当前登录账户能解密，全程不写明文文件，日志也不会打印密码。

使用方法

  • 双击 启动-成贤校园网登录.bat 打开图形界面
  • 填账号密码、选出口线路，点「连接并自动登录」
  • 开机自启：先勾选保存密码，再双击 创建开机自启.bat，开机后台自动连接并登录

命令行（可选）

  • powershell -File CXXY-CampusNet.ps1 -Mode Check —— 只检查网络状态
  • -Mode Login -User 卡号 -Pass 密码 —— 命令行直接登录
  • -Mode Auto —— 有保存的密码就自动登录，没有就连接并弹认证页

常见提示对照

提示含义与处理
账号不存在输入的不是校园门户账号，或学号输错
用户名或密码不正确门户密码错误，以修改后的密码为准
unbind isp uid选了电信 / 移动出口，但没有在自助服务里绑定运营商宽带账号
运营商账号 / 密码不正确绑定的手机号不对，或该手机号没开通宽带业务
登录超限同一时间最多 3 台设备在线，到自助服务注销不用的设备
认证页不弹出检查是否插着有线网线，拔出后重试

技术栈

  • PowerShell 5.1（Windows 自带，无需安装）
  • 连接无线：netsh wlan；网络请求：Invoke-WebRequest
  • 表单自动填充：解析认证页真实字段，保留隐藏字段再提交
  • 密码加密：Windows DPAPI，账户级保护
