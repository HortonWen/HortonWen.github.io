🧰 校园网一键连接 / 自动登录

解决 Windows 电脑连上 Student_CX 后不弹认证页、每次都要手动输账号的问题。

查看 GitHub 仓库

功能

  • 一键连接无线信号，并在本机没有配置时自动创建无线配置
  • 等待认证网关就绪，先自动提交登录表单，成功后直接上网
  • 自动登录失败时，自动弹出认证页面，手动输一次也能用
  • 单独的「只打开认证页」「检查网络状态」「自助服务」入口
  • 可选开机自启：后台尝试连接并登录

密码安全

默认不保存密码，每次手动输入。只有勾选「本机加密保存」后，才会用 Windows 账户级加密（DPAPI）存到本机，仅当前登录账户能解密，不写任何明文文件。

使用

  • 双击 启动-成贤校园网登录.bat 打开图形界面
  • 填入账号密码、选择出口线路，点「连接并自动登录」
  • 想开机自启：先保存密码，再双击 创建开机自启.bat
