把重复、繁琐的校园系统操作，沉淀成可以直接被 AI Agent 调用的技能。

cxxy-campus

Python仅标准库已开源

一套针对校园系统的自动化工具，面向个人日常使用，AI 可以按技能说明直接调用。

能做什么

  • 官网通知与学科竞赛目录抓取 —— scripts/website.py
  • 学科竞赛管理系统：登录、列项目、查已报名、项目详情 —— scripts/competition.py
  • 数字校园门户登录、教务系统单点登录 —— scripts/portal.py

实现要点

  • 只用 Python 标准库（urllib + http.cookiejar），零第三方依赖
  • 分别处理 GBK / UTF-8 页面编码，保持会话 Cookie 完成跨系统单点登录
  • 账号密码只由使用方临时提供，仓库不保存任何凭证

仓库：github.com/HortonWen/seu-cxxy-campus-skill

配套的 Windows 端校园网登录工具见 小工具页面。
