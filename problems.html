已解决

火山引擎 ve CLI 安装失败 已解决

现象：Windows 上安装 @volcengine/cli 时，解压步骤报错 Expand-Archive 命令所在模块无法加载。

原因：Codex 运行环境自带的 PowerShell 模块目录里有一份新版压缩模块，遮蔽了 Windows 自带的模块，导致自动加载失败。

解法：安装前把 PSModulePath 指向系统模块目录，再重装即可成功。

GitHub 推送连接被重置 已解决

现象：git push 到 github.com 时，TCP 已建立但请求被对端重置，Recv failure: Connection was reset。

解法：改用 GitHub 的 SSH 443 通道（ssh.github.com:443），配一把专用 SSH 密钥后推送恢复正常。

未解决 / 待处理

arkcli 的 update_execution_boundary 拦截 未解决

现象：arkcli 执行业务命令前自检失败：Windows 文件句柄解析到应用私有目录里的同一份硬链接文件，而不是 npm 全局目录，命令被拦下。

已尝试：关闭自动更新（update.mode=disabled）、直接调用 exe、核对路径，均未绕开；判断与该应用的目录虚拟化有关。

待办：找到官方对“非规范安装路径”的放行方式，或等新版本修复。

ve 技能需要火山引擎 AK/SK 未解决

现状：ve 命令行与技能已装好，但身份检查返回“未配置登录凭证”。方舟的 ARK API Key 与 ve 需要的火山主账号 AK/SK 不是同一套凭证，不能通用。

待办：提供 AK/SK 或走浏览器登录后才能继续。

校园网自动登录接口待实测 待验证

现状：登录工具按学校公开指南（认证网关、触发地址）与常见的 Dr.COM 认证方式实现，但编写环境不在校园网内，无法实网验证。

兜底：无论自动登录是否成功，工具都会保证把认证页弹出来。

待办：在校园环境实测一次，把卡住时的日志发回来再调整。

GitHub API 间歇性 SSL 中断 未定位根因

现象：api.github.com 偶发 SSL connection could not be established 或 unexpected EOF，重试后通常恢复。

临时对策：所有脚本加重试；根因未明，待观察网络环境变化。
