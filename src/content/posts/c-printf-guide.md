`printf` 是 C 语言最核心的输出函数，但它的格式化控制符种类繁多，初学者往往只记住了 `%d` 和 `%s`，遇到精度控制、对齐补零、进制输出时就无从下手。这篇文章把 `printf` 的所有格式控制符做一次完整梳理，从基础到进阶，帮你建立起系统的认知。

![printf 格式化输出总览](/images/c-printf-01.webp)

## 基础格式符

下面是最常用的格式符，覆盖了日常开发中的绝大多数场景：

| 格式符 | 作用 | 示例 |
|---|---|---|
| `%d` | 十进制有符号整数（int） | `printf("%d", 123);` |
| `%i` | 同 `%d`，十进制整数 | `printf("%i", -45);` |
| `%u` | 十进制无符号整数 | `printf("%u", 666);` |
| `%f` | 浮点数 float/double，默认 6 位小数 | `printf("%f", 3.14);` |
| `%lf` | double（scanf 专用，printf 中 `%f` 兼容 double） | — |
| `%c` | 单个字符 | `printf("%c", 'A');` |
| `%s` | 字符串 | `printf("%s", "hello");` |
| `%x` | 小写十六进制 | `printf("%x", 15); // f` |
| `%X` | 大写十六进制 | `printf("%X", 15); // F` |
| `%o` | 八进制 | `printf("%o", 8); // 10` |
| `%p` | 输出变量内存地址（指针） | `printf("%p", &a);` |
| `%%` | 输出一个百分号 `%` | `printf("%%");` |
| `%n` | 把已输出字符数存入对应 int 指针（极少用） | — |

### 整型与实型的对比

理解整型和实型的区别有助于选对格式符：

| 对比项 | 整型（int，`%d`） | 实型（float/double，`%f`） |
|---|---|---|
| 存储内容 | **整数**，没有小数部分 | **小数/浮点数**，包含整数、小数、科学计数 |
| 数值示例 | 10、-5、0、999 | 3.14、-0.5、12.0、2.9e3 |
| 内存存储 | 纯二进制整数，精确无误差 | 符号位 + 指数 + 尾数，存在精度丢失 |
| 运算特点 | 加减乘除结果为整数，除法会截断小数 | 运算保留小数，支持小数运算 |
| 输出占位符 | `%d`（十进制整数） | `%f`（默认 6 位小数浮点数） |

## 长短整型适配

不同长度的整型需要搭配对应的长度修饰符，否则输出结果可能出错：

| 格式符 | 类型 |
|---|---|
| `%hd` | short int |
| `%ld` | long int |
| `%lld` | long long int |
| `%hu` | unsigned short |
| `%lu` | unsigned long |
| `%llu` | unsigned long long |

## 浮点扩展格式符

除了基本的 `%f`，还有几种专门用于浮点数的格式符：

| 格式符 | 作用 |
|---|---|
| `%e` | 科学计数法（小写 e），如 `2.100000e+01` |
| `%E` | 科学计数法（大写 E），如 `2.100000E+01` |
| `%g` | 自动去掉多余小数零，选最短格式 |
| `%G` | 大写科学计数版 `%g` |

## 修饰符详解

`printf` 的真正威力在于修饰符。通用结构为：`%[标志][宽度][.精度][长度]类型`。

### 标志位

- **`-`**：左对齐（默认右对齐）

```c
printf("%-5d", 12); // "12   "
printf("%5d", 12);  // "   12"
```

- **`+`**：正数显示正号

```c
printf("%+d", 5); // +5
```

- **空格**：正数留空格，负数显示负号。
- **`0`**：空位补 0 而非空格

```c
printf("%05d", 12); // 00012
```

- **`#`**：八进制加 `0`、十六进制加 `0x`/`0X`

```c
printf("%#x", 10); // 0xa
```

### 宽度

数字表示最小输出宽度，不足时补空格或 0：

```c
printf("%6d", 123); // "   123"
```

### .精度

- **整数**：最少数字位数，不足前补 0。`%.5d` → 输入 12 → `00012`
- **浮点**：小数点后保留位数。`%.2f` → 3.1415 → `3.14`
- **字符串**：最多输出字符长度。`%.3s` → `"abcd"` → `"abc"`

### 长度修饰

即上文提到的 `l`、`ll`、`h` 等，用于匹配不同大小的整型。

## 综合示例

把上面所有知识点串起来看一个完整的例子：

```c
#include <stdio.h>
int main()
{
    int a = 15;
    double b = 3.1415926;
    char c = 'Z';
    char str[] = "C语言";

    printf("整数：%d\n", a);
    printf("十六进制：%#X\n", a);
    printf("浮点数保留2位：%.2f\n", b);
    printf("左对齐占8位：%-8s\n", str);
    printf("补0宽度5：%05d\n", a);
    printf("地址：%p\n", &a);
    return 0;
}
```

## 小结

- `printf` 的格式控制符分为基础类型符、长度修饰符、浮点扩展符三大类，掌握 `%d`、`%f`、`%s`、`%x`、`%o` 即可覆盖大部分场景。
- 修饰符的通用结构是 `%[标志][宽度][.精度][长度]类型`，标志位控制对齐和符号显示，宽度控制最小输出宽度，精度控制小数位数或字符串截断。
- 长短整型必须搭配正确的长度修饰符（`h`、`l`、`ll`），否则输出结果不可预测。
- `%g` 能自动选择最短的浮点表示形式，在不确定数值范围时特别有用。
