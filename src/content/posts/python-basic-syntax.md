Python 基础语法是学习这门语言的基石。它的核心在于简洁明了的语法规则、丰富的数据类型支持以及灵活的控制结构，使开发者能够快速上手并编写出可读性强的代码。这篇文章将从变量定义出发，依次覆盖数据类型、运算符、控制流、函数、输入输出、注释规范和异常处理，帮你建立起完整的 Python 基础语法框架。

## 变量与数据类型

### 变量

Python 的变量无需显式声明类型，直接赋值即可使用。命名规则是：由字母、数字、下划线组成，不能以数字开头，区分大小写，建议使用小写字母和下划线（如 `user_name`）。此外，Python 是动态类型语言，同一个变量可以赋不同类型的值。

```python
name = "Alice"      # 字符串
age = 25            # 整数
score = 95.5        # 浮点数
is_student = True   # 布尔值
```

### 基本数据类型

Python 支持多种内置数据类型：

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| **整数(int)** | 正负整数，无大小限制 | `10, -10` |
| **浮点数(float)** | 小数值，存在精度误差 | `3.14, -5.21` |
| **字符串(str)** | 文本数据，用引号包围 | `"Hello", 'World'` |
| **布尔(bool)** | 逻辑值，是 int 的子类 | `True(1), False(0)` |
| **复数(complex)** | 格式为 `a + bj` | `2.3 + 4.5j` |

### 复合数据类型

除了基本类型，Python 还提供了四种常用的复合数据结构：

- **列表(List)**：有序可变集合，用方括号 `[]` 定义

    ```python
    fruits = ["apple", "banana", "cherry"]
    numbers = [1, 2, 3, 4, 5]
    ```

- **元组(Tuple)**：有序不可变集合，用圆括号 `()` 定义

    ```python
    coordinates = (10, 20)
    colors = ("red", "green", "blue")
    ```

- **字典(Dictionary)**：无序键值对集合，用花括号 `{}` 定义

    ```python
    person = {"name": "Alice", "age": 25, "city": "New York"}
    ```

- **集合(Set)**：无序不重复元素集

    ```python
    unique_numbers = {1, 2, 3, 4, 5}
    ```

## 运算符

掌握了数据类型之后，接下来看看 Python 提供了哪些运算符来操作这些数据。

### 算术运算符

| 运算符 | 说明 | 示例 |
| --- | --- | --- |
| `+` | 加 | `5 + 3 = 8` |
| `-` | 减 | `5 - 3 = 2` |
| `*` | 乘 | `5 * 3 = 15` |
| `/` | 除（结果为浮点数） | `10 / 4 = 2.5` |
| `//` | 整除（向下取整） | `10 // 4 = 2` |
| `%` | 取模（余数） | `10 % 4 = 2` |
| `**` | 幂运算 | `10 ** 2 = 100` |

### 比较运算符

比较运算符返回 `True` 或 `False`：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）。

### 逻辑运算符

- `and`：全真为真
- `or`：一真为真
- `not`：取反

### 赋值运算符

除了基本的 `=` 赋值外，Python 还支持 `+=`、`-=`、`*=`、`/=` 等复合赋值运算符，可以让代码更简洁。

## 控制流

有了数据和运算符，就可以通过条件判断和循环来控制程序的执行流程了。

### 条件语句

Python 使用**缩进**表示代码块，而非大括号：

```python
if age > 18:
    print("成年人")
elif age > 12:
    print("青少年")
else:
    print("儿童")
```

### 循环语句

- **for 循环**：遍历可迭代对象

    ```python
    for i in range(5):  # 0到4
        print(i)
    ```

- **while 循环**：条件驱动的重复执行

    ```python
    count = 0
    while count < 5:
        print(count)
        count += 1
    ```

### 循环控制

在循环体内，可以使用三个关键字改变执行流程：`break` 立即终止整个循环，`continue` 跳过当前迭代进入下一轮，`pass` 作为空语句占位。

## 函数

当一段逻辑需要被反复使用时，就可以把它封装成函数。

### 定义与调用

```python
def greet(name):
    """这是一个向指定名字打招呼的函数"""
    return f"Hello, {name}!"

message = greet("Alice")
print(message)  # 输出 "Hello, Alice!"
```

### 参数类型

Python 函数的参数传递非常灵活，支持位置参数（按顺序传递）、关键字参数（通过参数名指定）、默认值参数（定义时指定默认值）以及可变参数（`*args` 接收位置参数，`**kwargs` 接收关键字参数）。关于函数参数的详细用法，后续会有专文展开。

## 输入输出

程序与用户交互离不开输入和输出。

### 输入

```python
name = input("请输入你的名字：")
age = int(input("请输入你的年龄："))  # 需转换类型
```

注意 `input()` 返回的是字符串，如果需要数字类型，必须手动转换。

### 输出

```python
print("Hello, World!")
print(f"你的名字是：{name}")  # f-string格式化
```

f-string 是 Python 3.6 引入的格式化语法，写法直观，推荐优先使用。

## 注释

良好的注释习惯能让代码更易读、更易维护。

### 单行注释

```python
# 这是单行注释
print("Hello")  # 右边内容也是注释
```

### 多行注释

```python
"""
这是多行注释
可以换行书写
"""
```

## 代码风格与规范

写完能运行的代码只是第一步，写出规范的代码同样重要：

- **缩进**：官方建议使用 4 个空格，**严禁混用空格和 Tab**。
- **命名**：变量和函数使用小写字母和下划线（`snake_case`），类名首字母大写。
- **PEP 8**：遵循 Python 官方编码规范，保持代码一致性。
- **注释**：为复杂逻辑添加解释性注释。

## 异常处理

最后，程序运行时难免出错，合理的异常处理能让程序更加健壮：

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("除数不能为0！")
except Exception as e:
    print(f"发生错误：{e}")
finally:
    print("无论是否出错都会执行")
```

## 小结

- Python 变量无需声明类型，支持动态赋值；内置五种基本数据类型和四种复合数据结构。
- 算术、比较、逻辑和赋值四类运算符覆盖了日常开发中的绝大多数计算需求。
- 条件语句用缩进而非大括号划分代码块，for 和 while 两种循环配合 break/continue 控制流程。
- 函数通过 `def` 定义，支持多种参数传递方式；输入输出分别用 `input()` 和 `print()` 配合 f-string。
- 遵循 PEP 8 规范、合理使用注释和异常处理，是写出高质量 Python 代码的基础。
