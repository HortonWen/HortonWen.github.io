模板是 C++ 实现泛型编程的核心工具，它允许编写与具体数据类型无关的通用代码，在编译时通过类型参数化实现代码复用。这篇文章从"为什么需要模板"讲起，覆盖函数模板、类模板、模板特化和实际应用，帮你建立完整的模板编程基础。

## 为什么需要模板

在没有模板的时代，如果要写一个求最大值的函数，就得为每种类型写一个重载：

```cpp
int max(int a, int b) { return a > b ? a : b; }
double max(double a, double b) { return a > b ? a : b; }
// ... 每种类型都要写一遍
```

这些函数的逻辑完全相同，只是类型不同。模板解决了这个问题：**将类型作为参数传递**，一份代码适配所有类型。修改算法时只需改一处，新增类型时无需修改模板代码。而且这一切发生在编译时，生成的代码与手写特定类型版本完全相同，零运行时开销。

## 函数模板

### 定义与调用

以 `template <typename T>` 或 `template <class T>` 开头声明类型参数（`typename` 和 `class` 在此处等价，但 `typename` 更推荐）：

```cpp
template <typename T>
T max(T a, T b) {
    return a > b ? a : b;
}
```

调用时有两种方式：

- **隐式实例化**：`max(3, 5)` — 编译器自动推导 `T` 为 `int`。
- **显式实例化**：`max<int>(3, 5)` — 明确指定 `T` 为 `int`。

隐式推导方便但有局限，比如 `max(3, 5.0)` 会因 `int` 和 `double` 无法统一推导而报错，此时需要显式指定。

## 类模板

了解了函数模板后，来看类模板。类模板在类定义前添加模板声明：

```cpp
template <typename T>
class Stack {
public:
    void push(const T& data);
private:
    T* _array;
    size_t _capacity;
    size_t _size;
};
```

与函数模板不同，类模板实例化时**必须显式指定类型**，编译器无法自动推导：

```cpp
Stack<int> st;    // 正确
Stack st;         // 错误：缺少模板参数
```

## 模板参数类型

模板参数不止类型参数一种：

- **类型参数**：`typename T` 或 `class T`，最常用。
- **非类型参数**：编译期常量值（如整数），但不能是浮点数或字符串。例如 `template <int N> class Array {};`。
- **可变参数**：支持任意数量的类型参数，`template <typename... Args>`，这是 C++11 引入的特性。

## 模板实例化

模板在**编译阶段**展开，而非运行时。编译器根据调用时的具体类型生成对应的代码版本：

- **隐式实例化**：编译器根据调用参数自动推导类型并生成代码。
- **显式实例化**：程序员明确指定模板参数类型。

这意味着模板的错误可能在实例化时才被发现——如果某个类型不支持模板中使用的操作（比如 `minimum<T>` 要求 `T` 支持 `<` 运算符），编译器会在该类型被实例化时报错，而不是在模板定义时。

## 模板特化

当通用模板对某些类型不适用时，可以提供定制版本。

### 全特化

为特定类型提供完全定制的实现：

```cpp
template <>
const char* max<const char*>(const char* a, const char* b) {
    return strlen(a) > strlen(b) ? a : b;
}
```

这里对 `const char*` 做了特殊处理——比较字符串长度而非指针地址。

### 偏特化

仅针对部分模板参数进行特化，只适用于类模板。比如一个双参数模板可以只对第一个参数做特化。

## 使用注意事项

- **头文件实现**：模板的实现通常必须放在头文件中，因为编译器在实例化时需要看到完整定义。把模板实现放在 `.cpp` 文件中会导致链接错误。
- **错误定位困难**：模板错误信息往往冗长且指向实例化点而非定义点，调试难度较大。
- **编译开销**：大量模板实例化可能增加编译时间和生成的代码体积。
- **类型约束**：类型参数必须支持模板中使用的所有操作，C++20 的 concepts 特性可以改善这一点。

## 实际应用场景

- **容器类**：STL 中的 `vector`、`list`、`map` 等全部基于模板实现。
- **算法实现**：排序、搜索等算法可应用于不同类型的数据。
- **智能指针**：`unique_ptr`、`shared_ptr` 管理不同类型对象的内存。
- **编译时计算**：模板元编程可实现编译期计算（如斐波那契数列）。

## 小结

- 模板是 C++ 泛型编程的基础，通过编译时类型参数化实现代码复用，零运行时开销。
- 函数模板支持隐式和显式实例化，类模板必须显式指定类型参数。
- 模板特化（全特化/偏特化）允许为特定类型提供定制实现。
- 模板实现必须放在头文件中，注意类型约束和编译开销。
