Markdown 是一种轻量级标记语言，用纯文本就能写出格式丰富的文档。无论你是写技术博客、项目文档还是学习笔记，掌握它的基础语法都是第一步。这篇文章把最常用的语法点整理在一起，读完就能独立写出一篇结构清晰的 Markdown 文档。

## 基础格式速查

先来看几个最高频的行内格式：

| 效果 | Markdown 语法 | 备注 |
| :--- | :--- | :--- |
| **粗体** | `**粗体文本**` 或 `__粗体文本__` | 用两个星号或下划线包裹 |
| *斜体* | `*斜体文本*` 或 `_斜体文本_` | 用一个星号或下划线包裹 |
| ~~删除线~~ | `~~删除线文本~~` | 用两个波浪号包裹 |
| `行内代码` | `` `代码` `` | 用反引号（通常在 Esc 键下方）包裹 |

这些格式可以组合使用，比如 `***粗斜体***` 同时加粗和倾斜。

## 标题层级

使用 `#` 符号创建不同级别的标题，`#` 的数量代表标题级别，最多支持六级：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

> **提示**：`#` 后面必须加一个空格再写标题文字，否则部分渲染器不会识别为标题。

在博客系统中，一级标题通常由 Jekyll 自动从 front matter 的 `title` 字段生成，正文一般从 `##` 开始。

## 段落与换行

Markdown 对空白字符的处理和直觉稍有不同：

- **段落**：两个段落之间需要用**空行**（即一行完全为空）分隔。只按回车换行并不会产生新段落。
- **换行**：在一行末尾添加**两个或以上空格**再回车，可以实现强制换行（即 `<br>` 效果）。

这个规则是很多初学者的第一个坑——写了半天发现段落全粘在一起，往往就是忘了中间留空行。

## 列表

### 无序列表

使用 `-`、`*` 或 `+` 加上一个空格来创建项目符号，三者效果相同：

```markdown
- 项目一
- 项目二
  - 通过缩进（两个或四个空格）创建子列表
- 项目三
```

### 有序列表

使用数字加英文句点 `.` 和一个空格来创建：

```markdown
1. 第一项
2. 第二项
3. 第三项
```

实际渲染时，Markdown 解析器只看第一个数字，后续会自动排序。所以即使你全写成 `1.`，输出仍然是 1、2、3。

## 链接与图片

这两者的语法非常相似，区别仅在于图片前面多一个感叹号 `!`：

- **链接**：`[链接文字](链接地址)`
  - 示例：`[百度](https://www.baidu.com)` → [百度](https://www.baidu.com)
- **图片**：`![替代文字](图片地址)`
  - 替代文字在图片无法加载时显示，也用于无障碍访问。

## 表格

表格通过管道符 `|` 分隔单元格，第二行用连字符 `-` 定义表头，冒号 `:` 控制对齐方式：

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容A | 内容B | 内容C |
| 内容D | 内容E | 内容F |
```

表格是 Markdown 中最容易写错格式的语法之一。记住三个要点：每列之间用 `|` 隔开、第二行必须有 `-`、对齐冒号放在 `-` 的对应侧。

## 代码展示

### 行内代码

用单个反引号包裹：`` `console.log("hello")` ``。适合在正文中提到变量名、函数名或短命令。

### 代码块

大段代码使用三个反引号包裹，并在开头指定编程语言以获得语法高亮：

````markdown
```python
def hello():
    print("Hello, World!")
```
````

以 C++ 为例，标注 `cpp` 后关键字、注释、字符串会自动上色：

```cpp
#include <iostream>
using namespace std;

int main() {
    // 基础输出
    cout << "Hello, C++ in Markdown!" << endl;

    // 变量与循环
    int number = 42;
    for (int i = 0; i < 3; ++i) {
        cout << "数字: " << number << endl;
    }

    // Lambda 表达式
    auto square = [](int x) -> int {
        return x * x;
    };
    cout << "平方: " << square(5) << endl;

    return 0;
}
```

> **注意**：如果忘记写语言标识，代码仍会显示但不会有语法高亮。另外，不要用单个反引号包裹多行代码——那只会产生不换行的行内代码。

某些渲染器还支持在语言标识后加花括号来高亮特定行，如 `` ```cpp{1-5} ``，但这不是通用标准，在 GitHub 等平台不一定生效。

## 引用与分割线

最后补充两个常用的排版元素：

- **引用**：用 `>` 开头，常用于引述他人观点或强调提示内容。
  ```markdown
  > 这是一段引用
  ```
- **分割线**：三个或以上连字符 `---`、星号 `***` 或下划线 `___` 独占一行。**强烈建议前后各留一个空行**，避免被误识别为标题或其他元素。

如果你需要更花哨的分割线（如居中点状线、彩色线条），可以嵌入 HTML：

```html
<div style="text-align: center; color: #888; margin: 20px 0;">⋯ ⋯ ⋯</div>
```

不过要注意，GitHub 等平台出于安全考虑通常会过滤自定义样式，这种写法更适合本地编辑器或个人博客。

## 小结

- 标题、段落、列表是 Markdown 文档的骨架，务必掌握空行分段和 `#` 后加空格的规则。
- 表格、代码块、链接与图片覆盖了技术写作中绝大多数排版需求。
- 代码块记得标注语言以获得语法高亮；嵌套代码块时用四个反引号作为外层围栏。
- 引用和分割线让文章层次更清晰，分割线前后留空行是最稳妥的写法。
- 以上语法在 GitHub、Typora、VS Code、Obsidian 等主流平台通用，可以放心使用。
