函数是 Python 编程的核心构建块，它将一段可重复使用的代码组织成一个独立的单元，显著提高代码的模块化和复用性。这篇文章将从函数的基本定义出发，逐步深入到参数传递、返回值、变量作用域，最后介绍 Lambda 匿名函数和递归这两个进阶特性，帮你全面掌握 Python 函数语法。

## 函数定义与调用

### 定义函数

使用 `def` 关键字来定义一个函数：

```python
def function_name(parameters):
    """文档字符串（可选）"""
    # 函数体
    return value  # 可选
```

各组成部分的含义如下：

- **`def`**：定义函数的关键词。
- **`function_name`**：函数名称，遵循小写字母加下划线的命名规则（snake_case）。
- **`parameters`**：参数列表，可以为空，也可以包含多个参数。
- **函数体**：实现特定功能的代码，必须进行缩进。
- **`return`**：用于返回结果。如果没有 `return` 语句，函数默认返回 `None`。

### 调用函数

定义后，通过 `函数名()` 的方式来调用它：

```python
# 定义一个简单的函数
def greet(name):
    """向指定名字的人问好"""
    print(f"Hello, {name}!")

# 调用函数
greet("Alice")  # 输出: Hello, Alice!
```

## 参数传递

理解了基本的定义和调用之后，接下来看看 Python 灵活的参数传递机制。Python 的参数主要分为以下五种类型：

| 参数类型 | 语法 | 说明 | 示例 |
| :-- | :-- | :-- | :-- |
| **位置参数** | `func(a, b)` | 必须按顺序提供，数量要匹配。 | `power(2, 3)` |
| **关键字参数** | `func(a=1, b=2)` | 调用时通过参数名指定，顺序无关。 | `greet(name="Bob", age=25)` |
| **默认参数** | `func(a, b=10)` | 为参数提供默认值，调用时可省略。 | `greet("Charlie")` (age默认为18) |
| **可变位置参数** | `func(*args)` | 接收任意数量的位置参数，打包为元组。 | `sum_all(1, 2, 3, 4)` |
| **可变关键字参数** | `func(**kwargs)` | 接收任意数量的关键字参数，打包为字典。 | `info(name="David", city="SH")` |

使用时有两点需要特别注意：

- 参数组合的顺序必须是：位置参数 → `*args` → 默认参数 → `**kwargs`。
- 当默认参数是可变对象（如列表、字典）时，应使用 `None` 作为默认值，并在函数内部初始化，以避免意外的副作用。

## 返回值

函数可以通过 `return` 语句将结果返回给调用者，具体有三种情况：

- **无返回值**：省略 `return` 或仅有 `return`，默认返回 `None`。
- **单个返回值**：返回任意类型的单个对象。
- **多个返回值**：实际上是返回一个元组，支持使用元组解包接收。

```python
def calculate(a, b):
    sum_val = a + b
    diff_val = a - b
    return sum_val, diff_val  # 返回元组

# 接收多个返回值
x, y = calculate(10, 4)
print(x, y)  # 输出: 6 6
```

## 变量作用域

理解了参数和返回值之后，还需要弄清楚变量在函数内外的可见范围。变量的作用域决定了其在程序中可被访问的范围：

- **局部变量 (Local)**：在函数内部定义，只能在该函数内访问。函数执行完毕后，变量被销毁。
- **全局变量 (Global)**：在函数外部定义，整个程序范围内都可访问。若要在函数内修改全局变量，需使用 `global` 关键字声明。

Python 遵循 **LEGB** 规则进行变量查找：

1. **L (Local)**：局部作用域。
2. **E (Enclosing)**：嵌套的外层函数的非局部作用域。
3. **G (Global)**：全局作用域。
4. **B (Built-in)**：内置作用域（如 `print`、`len` 等）。

## 进阶特性

掌握了函数的基础用法之后，下面两个进阶特性能让你的代码更加简洁和优雅。

### 匿名函数 (Lambda)

Lambda 用于创建简单的、临时的函数，语法简洁，只能包含一个表达式：

```python
# 语法: lambda 参数: 表达式
add = lambda x, y: x + y
print(add(3, 5))  # 输出: 8

# 常与 sorted, map, filter 等函数配合使用
data = [(1, 5), (2, 1), (3, 3)]
sorted_data = sorted(data, key=lambda x: x[1])  # 按元组第二个元素排序
```

### 递归函数

递归是指在函数内部调用自身。使用递归必须定义**基线条件**（何时停止）和**递归条件**（何时调用自身），以避免无限循环：

```python
def factorial(n):
    """计算n的阶乘"""
    if n == 1:  # 基线条件
        return 1
    else:       # 递归条件
        return n * factorial(n - 1)

print(factorial(5))  # 输出: 120
```

## 小结

- 函数通过 `def` 关键字定义，没有 `return` 语句时默认返回 `None`。
- Python 支持位置参数、关键字参数、默认参数、`*args` 和 `**kwargs` 五种参数类型，组合使用时需遵循固定顺序。
- 多个返回值本质上是元组，可以用元组解包的方式接收。
- 变量查找遵循 LEGB 规则，修改全局变量需用 `global` 声明。
- Lambda 适合简短的一次性函数，递归需要明确基线条件以防止无限循环。
